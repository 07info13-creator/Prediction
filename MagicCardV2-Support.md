# Assistance — MagicCardV2

Dernière mise à jour : 26 septembre 2026

## À propos

MagicCardV2 est une application de divertissement destinée aux prestations de magie numérique sur iPhone.

## Besoin d'aide ?

Si vous rencontrez un problème avec MagicCardV2, vérifiez d'abord les points suivants :

- redémarrez complètement l'application ;
- vérifiez que l'iPhone dispose d'une version récente d'iOS compatible avec l'application ;
- si un effet utilise les mouvements de l'iPhone, assurez-vous que les capteurs de mouvement fonctionnent normalement ;
- si le comportement de l'application semble anormal après une mise à jour, redémarrez l'iPhone puis relancez l'application.

## Contact développeur

Pour demander de l'assistance, contactez le développeur via le profil GitHub associé à ce dépôt :

https://github.com/07info13-creator

Lors de votre demande, indiquez si possible :
- le modèle d'iPhone ;
- la version d'iOS ;
- la version de MagicCardV2 ;
- une courte description du problème rencontré.

## Confidentialité

MagicCardV2 ne collecte pas de données personnelles.

# Support — MagicCardV2

Last updated: September 26, 2026

## About

MagicCardV2 is an entertainment application designed for digital magic performances on iPhone.

## Need help?

If you experience an issue with MagicCardV2, first try the following:

- fully restart the application;
- make sure the iPhone is running a recent compatible version of iOS;
- if an effect relies on iPhone movement, make sure motion sensors are working normally;
- if the app behaves unexpectedly after an update, restart the iPhone and open the app again.

## Developer contact

For support, contact the developer through the GitHub profile associated with this repository:

https://github.com/07info13-creator

When contacting support, please include if possible:
- iPhone model;
- iOS version;
- MagicCardV2 version;
- a short description of the issue.

## Privacy

MagicCardV2 does not collect personal data.
